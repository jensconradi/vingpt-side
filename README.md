# vingpt-side

Nettsida vingpt.no (GitHub Pages): forside på norsk, svensk og engelsk, personvernsidene og
delingssider. **Forsidene bygges av `bygg.py`** (tekstene ligger der; `ikoner.json` har
SVG-ikonene) — rediger `bygg.py`, kjør `python3 bygg.py`, commit alt. Personvernsidene redigeres
for hånd. `sitemap.xml`, `robots.txt` og `llms.txt` lages av samme skript.
